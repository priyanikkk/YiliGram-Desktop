# YiliGram Desktop

Unofficial Telegram client for Windows and Linux, the desktop sibling of
[YiliGram](https://github.com/priyanikkk/YiliGram) for Android. Based on
[Telegram Desktop](https://github.com/telegramdesktop/tdesktop) 7.4.4 and the
[Telegram API](https://core.telegram.org/api). Not affiliated with Telegram.

## Download

[Releases](https://github.com/priyanikkk/YiliGram-Desktop/releases):

- `YiliGram-windows-x64.zip`: unpack and run `YiliGram.exe` (Windows 10 and newer, 64 bit);
- `YiliGram-linux-x64.tar.xz`: unpack and run `YiliGram`.

YiliGram keeps its data apart from Telegram Desktop (`%APPDATA%\YiliGram Desktop` on Windows,
`~/.local/share/YiliGramDesktop` on Linux), so both can be installed side by side.

## Changes from Telegram Desktop

- name, icon and window titles;
- Material 3 palette built from the YiliGram seed color `#8C7A5B` (replaces the blue accents and the
  green outgoing messages of the default theme);
- no update checks against Telegram's servers and no crash reports;
- own `api_id`.

Changes to submodules are kept as patches in `tools/yiligram/patches` and applied by
`tools/yiligram/apply_patches.sh`. Icons are generated by `tools/yiligram/gen_icons.py`.

## Building

GitHub Actions (`.github/workflows/build.yml`) builds Windows x64 and Linux x64. A tag `v*` publishes a
release. The repository secrets `TDESKTOP_API_ID` and `TDESKTOP_API_HASH` must hold the API
credentials from [my.telegram.org](https://my.telegram.org).

For a local build follow the upstream instructions in [docs](docs), and run
`tools/yiligram/apply_patches.sh` after `git submodule update --init --recursive`.
